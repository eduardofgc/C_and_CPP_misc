# Material

Repositório com implementações, exercícios e material de apoio desenvolvidos ao longo das disciplinas Algoritmos e Programação de Computadores e Estruturas de Dados e durante meu tempo como tutor. 

```
.
├── ED/         # Estruturas de dados comuns, reutilizadas ao longo dos exercícios
├── Extra/      # Arquivos miscelâneos 
└── Tutoria/    # Questões resolvidas na tutoria
```

### `ED/`
Implementações de estruturas de dados clássicas (listas, pilhas, filas, vetores, árvores, etc.).

### `Extra/`
Arquivos diversos que não se encaixam diretamente nas outras pastas.

### `Tutoria/`
Questões resolvidas e comentadas, organizadas para servir de material de apoio durante as sessões de tutoria.

## Compilando e executando

Os arquivos são em C. Para compilar um exercício individualmente:

```bash
gcc -Wall -o programa arquivo.c
./programa
```
